⚙ Setup Required

Open photos.html and set your DRIVE_FOLDER_ID and API_KEY at the top of the script. Follow the steps below:

1
Go to Google Drive → right-click your photos folder → Share → set to "Anyone with the link"
2
Copy the folder ID from the URL: drive.google.com/drive/folders/FOLDER_ID_HERE
3
Go to Google Cloud Console → Create Project → Enable Google Drive API → Create an API Key → Restrict it to Drive API
4
Paste both into the CONFIG block at the top of the JS section in this file.
5
For categories: create sub-folders inside your main folder (e.g. "Day 1", "Day 2", "Stage"). They become the filter tabs automatically.
